# 假设评估准则文档 (Hypothesis Evaluation Protocol)

**目标：** 指导 AI Agent 识别、评估并过滤用户或其它 Agent 提出的假设，确保后续的推理、实验或行动基于高质量的逻辑基础。

## 核心评估原则

一个“好的假设”必须满足以下五个维度（按重要程度排序）：

### 1. 可证伪性 (Falsifiability)
* **定义：** 假设必须在逻辑上存在被证明为“错误”的可能性。
* **判断标准：** 是否可以设计一个实验或寻找一组数据来推翻该假设？
* **不合格特征：** 包含“无论发生什么都正确”的循环论证，或涉及无法观测的超自然因素。

### 2. 预测力与解释力 (Predictive & Explanatory Power)
* **定义：** 假设不仅要解释现有现象，还要能预测未来的结果。
* **判断标准：** 如果该假设成立，是否能推导出明确的“如果...那么...”逻辑？
* **不合格特征：** 描述过于笼统（如“事情会变好”），无法指导具体的预测。

### 3. 简洁性 / 奥卡姆剃刀 (Parsimony / Occam's Razor)
* **定义：** 在解释能力相同的情况下，假设应尽量简单，减少不必要的变量。
* **判断标准：** 该假设是否引入了过多未经证实的额外前提？
* **不合格特征：** 逻辑链条过于冗长，依赖于一连串极其罕见的巧合。

### 4. 范围明确性 (Specificity & Scope)
* **定义：** 假设必须有清晰定义的边界和变量。
* **判断标准：** 主语、谓语和条件是否具体？变量是否可衡量？
* **不合格特征：** 使用模糊词汇（如“很多”、“可能”、“某种程度”）。

### 5. 相容性 (Consistency)
* **定义：** 假设应与已知的客观事实或已被广泛验证的科学原理相协调（除非该假设的目的是为了挑战旧理论）。
* **判断标准：** 它是否无视了已存在的反向证据？

---

## AI Agent 判断逻辑流程图

当 Agent 接收到一个假设 $H$ 时，应执行以下自检：

1.  **明确性检查：** $H$ 是否定义了清晰的因果关系？（如果 $A$，则 $B$）
2.  **变量识别：** $H$ 中的核心变量是否可以被观察或测量？
3.  **对立面推演：** 什么样的证据会出现并直接证伪 $H$？
4.  **价值评估：** 验证这个假设的成本与它带来的收益（知识增量或决策指导）是否成正比？

## 评分表 (Scorecard for Agents)

Agent 可以对假设进行 1-5 分的打分：

| 维度 | 评分 (1-5) | 判定参考 |
| :--- | :--- | :--- |
| **可测性** | | 是否能通过数据或逻辑推理验证？ |
| **逻辑简洁** | | 是否避免了过度假设？ |
| **可操作性** | | 是否能根据该假设采取下一步行动？ |
| **风险程度** | | 若假设错误，导致的后果是否在可控范围内？ |

## 示例应用

* **差的假设：** “用户点击这个按钮是因为他们心里想尝试新事物。”（*不可证伪，无法衡量心理活动*）
* **好的假设：** “将订阅按钮的颜色从灰色改为红色，会使 18-25 岁用户的点击率提升 $15\%$。”（*具体、可测、可证伪、有预测力*）

## 如何应对差的假设

> **提示给执行 Agent：** > 如果你判定一个假设为“差”，请不要直接丢弃，应尝试向对方反馈：“该假设缺乏可测性，请尝试补充具体的衡量指标或时间范围。”
