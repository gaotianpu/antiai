# 新闻灵感商业创意生成器

## 核心原理

```
新闻文本 → 四维扫描 → 创意涌现 → 输出创意
```

从新闻中寻找三类信号，用模板重组成商业构想：

| 信号类型 | 寻找什么 | 对应热力学概念 |
|---------|---------|--------------|
| 能量信号 | 未被满足的需求、高涨的情绪、即将爆发的资本/注意力 | 能量流 |
| 物质信号 | 闲置、浪费、低效运转的资源、新技术/新基础设施 | 物质基础 |
| 熵增信号 | 混乱、等待、纠纷、不确定性、巨大的资源耗散 | 熵 |

## 生成流程

### 第一步：新闻解构（四维扫描）

仔细阅读新闻，按四个维度提炼关键线索：

- **能量信号**：哪些人群正表现出强烈渴望、焦虑或付费冲动？哪里有钱/注意力正在聚集？
- **物质信号**：哪些资源被闲置、浪费或低效运行？出现了什么新技术、新基础设施？
- **熵增信号**：哪些环节充满混乱、等待、纠纷、不确定性或巨大的资源耗散？
- **信息种子**：是否存在某种数据、排序、匹配或信任机制能解决上述混乱？

### 第二步：创意涌现（热力学重排）

使用以下四种思维模板重组元素：

#### 模板1：能量捕获型

思路：为新闻中积蓄的"能量洪流"修建渠道，使之持续、可控地流入某个商业系统。

句式：看到新闻中`[某群体]`对`[某事物]`的狂热/焦虑，可否创造一个`[订阅/会员/打赏]`机制，让这种情绪能量定期释放并转化为`[某服务/内容/体验]`？

#### 模板2：物质重排型

思路：将新闻中暴露的冗余、闲置资产，用信息连接、调度，激活其潜在做功能力。

句式：新闻中谈到大量`[闲置物品/空间/技能]`被浪费，可否建立一个`[平台/协议]`，用`[匹配算法/游戏化规则]`把它们变成`[可随时取用的服务/共享网络]`？

#### 模板3：熵减负熵型

思路：瞄准新闻中一个令人抓狂的混乱点，注入一种"超级信息结构"，大幅削减不确定性。

句式：新闻揭示了`[某领域]`极高的`[匹配摩擦/信任成本/决策瘫痪]`，可否设计一套`[动态评级/智能合约/预测模型]`，像麦克斯韦妖一样，只让优质`[交易/信息/人]`通过？

#### 模板4：耗散结构型

思路：在新闻提及的某个交叉地带，创造一个能自我维持、进化的"商业生命体"。

句式：如果把`[新闻中的A]`和`[新闻中的B]`组合成一个`[持续更新的数据飞轮/双边网络]`，能否涌现出一个全新的`[推荐系统/自组织社区/自动定价市场]`？

### 第三步：输出创意

每个创意包含：
- **创意名称**：简洁有力
- **一句话描述**：让用户立刻理解
- **热力学叙事**：用能量、物质、信息、熵的语言解释其运作逻辑

每次至少输出 **2 个不同方向**的创意。

## 输出模板

```
新闻标题：[标题]

─── 创意 1 ───
名称：[名称]
描述：[一句话]
热力学叙事：
  能量流：……
  物质基础：……
  有效负熵信息：……
  熵减：……

─── 创意 2 ───
名称：[名称]
描述：[一句话]
热力学叙事：
  能量流：……
  物质基础：……
  有效负熵信息：……
  熵减：……
```

## 自检清单

- [ ] 已从新闻中提取能量/物质/熵增/信息种子四类信号
- [ ] 创意使用了至少一种思维模板
- [ ] 每个创意包含完整热力学叙事
- [ ] 输出了至少 2 个创意
- [ ] 创意天马行空，不设可行性限制

## 禁止事项

- 不对创意做可行性判断（那是 business-viability-judge 的职责）
- 不因"太离谱"而自我审查或过滤创意
- 不局限于新闻字面含义，鼓励跨领域联想
- 不要求用户提供额外信息，基于新闻内容即可

## 示例

新闻标题：《全球极端天气频发，城市内涝致大量地库车辆被淹》

创意1：按需"洪水保镖"订阅服务
- 描述：车主订阅后获赠模块化防水保护装置，接入实时风险预警与自动挪车网络
- 能量流：车主对风险的恐惧→稳定的月费
- 物质基础：轻量化防水材料 + 闲置拖车运力
- 负熵信息：气象微预测+排水模型的"水淹概率地图"
- 熵减：将"泡水-理赔-扯皮"高熵链转为预防性负熵循环

创意2："积水经济"动态保险市场
- 描述：让保险公司和投机者实时交易"内涝保单"的算法市场
- 能量流：天气灾难赔付能量 + 金融波动投机能量
- 物质基础：车辆实时位置 + 高频气象数据 + 智能合约
- 负熵信息：将气象/地形/位置/风险模型熔于一炉的动态精算引擎
- 熵减：消除漫长报案定损过程，风险瞬时转化为可交易信息
