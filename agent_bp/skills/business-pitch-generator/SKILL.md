# 商业模式电梯说服生成器

## 核心逻辑：投资人的"灵魂三问"

```
投资人潜意识只关心三个问题：
  1. 你赚的是什么"能量"？
     → 是不是稳固、持续增长的价值流？刚需还是伪需求？
  2. 为什么能量必然流向你？
     → 如何用信息/网络/品牌创造结构洼地，让价值流不可抗拒地汇集？
  3. 这个结构会自我强化还是会熵增崩溃？
     → 规模越大，核心是越坚固还是越混乱？
```

## 四层电梯说服结构（总时长 ≤ 60 秒）

### 第1层：能量宣言（前15秒，抓住痛点）

任务：用一句话指出未被满足的巨大"能量梯度"。

句式："在`[某个高熵、混乱的市场]`，`[某类特定人群]`正面临`[具体的痛苦/渴望]`，这背后是`[数额]`未被有效捕获的价值洪流。"

### 第2层：物质与负熵引擎（中间25秒，展示解法与壁垒）

任务：展示用"信息"重排"物质"，建立独一无二的能量捕获结构。

句式："我们通过`[关键技术/核心算法/网络规则]`，将`[闲置/低效的物质资产]`重排为`[高效的服务/产品]`。这个引擎每运转一次，就积累更多`[数据/用户关系/品牌认知]`，让我们能更精准地预测和匹配需求——就像一个自我进化的麦克斯韦妖，让价值自动流向我们。"

### 第3层：熵增免疫（随后15秒，证明结构坚固）

任务：直接点出传统模式的熵增死穴，解释自己为何天生免疫。

句式："传统模式困于`[高昂的库存折旧/失控的服务质量/不可扩展的个人手艺]`，规模越大越脆弱。而我们的核心不是拥有重资产，而是拥有`[让资产高效流动的规则]`，规模每扩大一倍，边际管理成本反而`[递减/可控]`，天然抵抗无序。"

### 第4层：终局画面（最后5秒，描绘未来）

任务：勾勒该低熵结构主导市场的样子。

句式："最终，我们将成为这个领域`[价值流动的基础设施/供需匹配的超级大脑]`，让所有`[目标用户]`都通过我们完成`[核心需求]`。"

## 生成流程

```
输入（Idea 描述） → 提取灵魂三问答案 → 填充四层模板 → 输出电梯说服
```

### 输入提炼

从用户描述或商业计划中提取：

| 要素 | 对应第几层 |
|------|-----------|
| 目标市场与痛点 | 第1层 能量宣言 |
| 技术/算法/壁垒 | 第2层 负熵引擎 |
| 核心资产类型 | 第2层 物质重排 |
| 传统模式的缺陷 | 第3层 熵增免疫 |
| 规模效应特征 | 第3层 边际成本 |
| 终局愿景 | 第4层 终局画面 |

### 填充模板

将提炼出的要素按对应层级的句式填充，形成连贯叙事。

## 输出模板

```
─── 电梯游说 ───

[第1层 能量宣言]
在[市场]，[人群]正面临[痛点]，这背后是[价值规模]未被有效捕获的价值洪流。

[第2层 负熵引擎]
我们通过[核心技术]，将[物质资产]重排为[产品/服务]。这个引擎每运转一次，就积累更多[信息资产]，就像一个自我进化的麦克斯韦妖。

[第3层 熵增免疫]
传统模式困于[传统缺陷]，而我们拥有[让核心运转的规则]，规模越大边际成本越[趋势]，天然抵抗无序。

[第4层 终局画面]
最终，我们将成为[领域]的[终局定位]。
```

## 自检清单

- [ ] 开头 15 秒点明了巨大的能量梯度
- [ ] 解释了如何用信息重排物质形成壁垒
- [ ] 回应了投资人对规模后是否崩溃的隐忧
- [ ] 结尾描绘了清晰的终局画面
- [ ] 总时长控制在 60 秒以内

## 禁止事项

- 不编造数据或市场规模（若用户未提供，使用"数额级"如"百亿级"）
- 不替用户设定融资金额或估值
- 不使用行业黑话或晦涩术语（热力学注脚放在括号内）
- 不评价该商业模式的可行性（那是 judge 的职责）

## 示例

```
─── 电梯游说：宠物寄养共享平台 ───

在宠物寄养市场，无数家庭在节假日为毛孩子无处可去而焦虑，这个市场的能量每年都在以脉冲形式爆发，却从未被稳定捕获。

我们打造的，是一个能自建信任网络的寄养匹配引擎。它把社区里无数个安全的家庭空间，重排成一个分布式的、有温度的寄养网络。每一次寄养积累的双向评价和实时视频，正在喂养我们的信任算法——这个算法让优质寄养家庭浮出，让焦虑的主人精准匹配，就像一个麦克斯韦妖，不断为系统吸入信任，排出风险。

传统宠物店模式被高昂的房租和防疫风险死死压住，规模不经济。而我们不拥有任何一间笼子，只拥有让信任流动的规则。每增加一个社区，网络的密度和信任度就更高，服务成本几乎不增，天然抵抗规模化的混乱。

最终，我们就是宠物寄养领域的Airbnb，是这个万亿宠物市场里，情感信赖的基础设施。
```
