# 新闻 → 商业计划书（组合工作流）

组合 `news-idea-generator` → `business-viability-judge` → `business-launch-advisor` → `business-pitch-generator`，从一篇新闻稿完整输出一份相对可行的商业计划书。

## 工作流总览

```
读取 raw/news_index.md → 取首条 [ ] 新闻
     │
     ▼
[Step 0] 去重检查
     提取新闻核心能量流 → 与 bplans/index.md 已有条目对比
     ├─ 高度相似 → 追加到 bplans/skipped.md → raw/news_index.md 标记 [s] → 回 [循环]
     └─ 无重复 → 进入 Step 1
     │
     ▼
[Step 1] news-idea-generator
     四维扫描 → 产出 ≥2 创意 → 持久化到 bplans/<ID>/01-ideas.md
     │
     ▼
[Step 2] business-viability-judge
     逐创意四维诊断 → 排序取第 1（自动选定）→ 持久化到 02-viability.md
     │
     ▼
[Step 3] business-launch-advisor
     按资金量级输出启动方案 → 持久化到 03-launch-plan.md
     │
     ▼
[Step 4] business-pitch-generator
     生成电梯游说 → 持久化到 04-pitch.md
     │
     ▼
[Step 5] 最终整合
     从 01~04 提取摘要 → 生成摘要索引页 05-business-plan.md
     │
     ▼
[收尾] 追加一条到 bplans/index.md → raw/news_index.md 标记 [x] + 日期
     │
     ▼
[循环] index 仍有 [ ]？
     ├─ 是 → 取下一篇，回 Step 0
     └─ 否 → 通知用户全部完成
```

## 输出目录规范

每篇新闻的处理产物统一存放到 `bplans/<新闻ID>/` 下：

| 步骤 | 文件名 | 内容 |
|------|--------|------|
| Step 1 | `01-ideas.md` | 新闻解构 + 创意列表 |
| Step 2 | `02-viability.md` | 四维诊断 + 可行性评级 + 自动选定创意 |
| Step 3 | `03-launch-plan.md` | 分级精算 + 启动路线 |
| Step 4 | `04-pitch.md` | 电梯游说文案 |
| Step 5 | `05-business-plan.md` | 摘要索引页，链接指向 01~04 原文 |
| — | `index.md` | 所有已生成计划的索引 |
| — | `skipped.md` | 因去重跳过的记录 |

## 前置条件

- 用户提供一篇新闻稿（链接或全文）
- 资金量级可选：用户指定则输出对应方案；未指定则输出全部 4 种（10万 / 50万 / 100万 / 500万）

## 分步执行指令

### Step 0：去重检查

读取新闻稿，提取**核心能量流**（谁为什么付费），与 `bplans/index.md` 已有条目逐一对比：

- 如果新闻的核心价值主张、目标用户群、能量捕获逻辑与某已有计划**高度相似**（如同样是"车主为车辆防洪付费"）：
  1. 追加一条记录到 `bplans/skipped.md`（格式见下文）
  2. 将 `raw/news_index.md` 对应条目标记为 `[s]` 而非 `[x]`
  3. 不创建 `bplans/<新闻ID>/` 目录
  4. 直接跳转到 [循环] 检查下一篇
- 否则，进入 Step 1

**去重判定标准**（满足任意两条即判定为高度相似）：
- 同一类目标用户（如均为车主/均为小微企业/均为家长）
- 同一类付费动机（如均为风险管理/均为效率提升/均为社交需求）
- 同一类能量捕获方式（如均为订阅制/均为平台抽成/均为按次付费）

**`skipped.md` 追加格式**：

```
| {新闻ID} | {相似对象ID} | {具体相似原因} | {日期} |
```

### Step 1：新闻解构 + 创意发散

调用 `news-idea-generator` 的执行逻辑：

1. 四维扫描新闻：提取能量信号、物质信号、熵增信号、信息种子
2. 使用 4 种思维模板（能量捕获/物质重排/熵减负熵/耗散结构）生成创意
3. 输出 ≥2 个创意，每个附带完整热力学叙事
4. **持久化**：将结果写入 `bplans/<新闻ID>/01-ideas.md`

### Step 2：可行性筛选

对 Step 1 输出的每个创意，逐一调用 `business-viability-judge` 的四维诊断：

- 能量流评估
- 物质基础评估
- 有效负熵信息评估
- 熵增风险评估

输出每个创意的可行性评级，按以下规则排序：

```
rating 排序：靠谱 > 有缺陷 > 不靠谱
同 rating 时：能量流 > 负熵信息 > 物质基础 > 熵增风险
```

取排名第 1 的创意作为**自动选定创意**（不再经过用户确认门控）。

**持久化**：将诊断结果写入 `bplans/<新闻ID>/02-viability.md`，末尾标明自动选定结果。

### Step 3：精算与启动规划

调用 `business-launch-advisor`：

1. 确定资金量级处理策略：
   - 若用户明确指定一个量级 → 按该量级输出
   - 若用户说"每种都处理"或未指定 → 输出全部 4 种量级（10万 / 50万 / 100万 / 500万）
2. 每种量级输出对应的精算重点、行动路线、熵增预警线
3. **持久化**：将方案写入 `bplans/<新闻ID>/03-launch-plan.md`

### Step 4：电梯说服

调用 `business-pitch-generator`：

1. 基于选定的 Idea 与 Step 3 的信息，提取灵魂三问答案
2. 填充四层说服模板
3. 输出电梯游说文案
4. **持久化**：将文案写入 `bplans/<新闻ID>/04-pitch.md`

### Step 5：最终整合

生成 `bplans/<新闻ID>/05-business-plan.md`，格式为**摘要索引页**，链接指向 01~04 文件，不重复全文。

**从各文件提取的内容映射**：

| 商业计划书章节 | 来源文件 | 提取内容 |
|--------------|---------|---------|
| §1 创意来源 | `01-ideas.md` | 新闻标题 + 四维扫描表格 |
| §2 商业创意 | `01-ideas.md` + `02-viability.md` | 创意名称 + 一句话描述 + 热力学逻辑 + 评级 |
| §3 可行性评估 | `02-viability.md` | 评级 + 类比案例 + 关键风险 + 修正建议 |
| §4 启动方案 | `03-launch-plan.md` | 按资金量级输出精算重点/行动路线/预警线 |
| §5 完整内容 | — | 用列表链接到 01~04 文件原文 |

### 收尾：更新索引

1. **追加到 `bplans/index.md`** — 在表格末尾追加一行，格式固定：
   ```
   | {新闻ID} | {创意名称} | {评级} | {日期} | ✅ 已完成 |
   ```
   （新闻ID 列嵌入链接指向对应 `05-business-plan.md`）

2. **标记 `raw/news_index.md`** — 将对应新闻条目的 `[ ]` 改为 `[x]`，追加日期

### 循环：指向下一篇

检查 `raw/news_index.md` 中是否还有 `[ ]` 或 `[s]` 未处理条目：
- 有 `[ ]` → 取第一条，回到 Step 0 开始下一轮
- 仅有 `[s]` 或无 → 通知用户"全部新闻已处理完毕"

## 自检清单

- [ ] Step 0：已与 `bplans/index.md` 完成去重对比
- [ ] 若去重命中：已追加到 `bplans/skipped.md` + `raw/news_index.md` 标记 `[s]`
- [ ] 若未命中：从新闻中提取了四类信号
- [ ] 生成了 ≥2 个创意
- [ ] 每个创意完成了四维诊断
- [ ] Step 2 自动选定了排名第 1 的创意
- [ ] Step 3 覆盖了用户要求的资金量级
- [ ] 生成了完整的四层电梯游说
- [ ] 输出了摘要索引页 `05-business-plan.md`（无全文重复）
- [ ] 追加了记录到 `bplans/index.md`（格式符合规范）
- [ ] 更新了 `raw/news_index.md` 标记已处理
- [ ] 检查了是否还有下一篇待处理

## 禁止事项

- 不合并子技能步骤（每步独立执行，不偷工减料）
- 不编造资金量级信息（必须询问用户）
- 不将"不靠谱"评级强行包装成商业计划书（若所有创意均不靠谱，需如实告知用户）
- 不自创热力学概念，严格沿用四个技能的术语体系
