# 商业模式热力学可行性判断器

## 核心概念映射

| 热力学概念 | 商业含义 | 判定线索 |
|-----------|---------|---------|
| 能量流 | 价值流（需求强度、付费意愿、现金流持续性） | 是否稳定、可扩展？一次性脉冲还是循环流？ |
| 物质基础 | 资源要素（资产、人力、技术、数据） | 能否被信息重排为更高效结构？能否轻量化？ |
| 有效负熵信息 | 可指导重排、捕获更多能量的结构化知识（算法、品牌、SOP、网络效应） | 能否自增强、可复制、形成匹配能力？ |
| 熵 | 系统无序度与耗散（管理成本、流失、折旧、摩擦） | 规模化后熵增是否超过能量捕获？是否可逆？ |

## 评估流程

```
解析 Idea → 四维诊断 → 综合判定 → 输出评级
```

### 第一步：解析 Idea

从用户描述中提取：

| 要素 | 内容 |
|------|------|
| 目标用户 | 谁为此付费？ |
| 核心价值 | 解决什么痛点或创造什么价值？ |
| 盈利模式 | 如何获取能量流（销售/订阅/抽成…）？ |
| 关键物质 | 需要哪些核心资产？ |
| 初始信息 | 已掌握或可快速生成的结构化知识？ |

### 第二步：四维诊断

#### 维度 A：能量流（外部价值可获取性）

**问题清单**：
- 市场是否存在明确且强烈的需求？（能量梯度陡不陡）
- 用户付费意愿有多高？支付是否高频、持续？
- 是否容易触达用户？（CAC 是否低）
- 能量流是否在增长？（市场扩张还是收缩）

**判定**：
- ✅ 高潜力：需求刚性，订阅/重复交易，市场增长，CAC 合理
- ⚠️ 风险：一次性售卖，需求疲软，获客成本极高
- ❌ 不可行：用户无付费意愿，能量流枯竭

#### 维度 B：物质基础（资源重排潜力）

**问题清单**：
- 主要物质是重资产还是轻资产？
- 能否通过信息重组提升利用率？
- 物质是否可能被"信息"替代？
- 资产利用率能达到多高？

**判定**：
- ✅ 高潜力：轻资产，或重资产可通过平台/算法盘活，可数字化
- ⚠️ 风险：资产重且难数字化，周转慢，闲置成本高
- ❌ 不可行：依赖稀缺不可复制物质，无信息壁垒

#### 维度 C：有效负熵信息（护城河生成能力）

**问题清单**：
- 业务流程是否自然产生数据？能否结构化为算法/SOP？
- 是否存在网络效应或数据飞轮？
- 信息能否直接降低不确定性？
- 信息结构是否自增强、可迭代？

**判定**：
- ✅ 高潜力：双边网络效应、数据飞轮、品牌心智、难复制 SOP
- ⚠️ 风险：无数据闭环，依赖个人直觉，经验无法固化
- ❌ 不可行：核心依赖无法结构化的个人手艺，规模不经济

#### 维度 D：熵增风险（系统耗散与僵化）

**问题清单**：
- 管理成本是否随规模剧增？
- 客户是否天然易流失？
- 外部变化是否使原有信息快速失效？
- 物理折旧或单点故障是否严重？

**判定**：
- ✅ 可控：边际成本递减，高留存，技术顺风，损耗低
- ⚠️ 风险：规模不经济，一次性客户，颠覆性赛道
- ❌ 不可行：熵增必然吞噬所有能量

### 第三步：综合判定

汇总四维结论，按决策树输出评级：

```
能量流是否为稳定循环流？
  ├─ 否 → ❌ 不靠谱（能量枯竭）
  └─ 是 → 物质能否被信息重排？
         ├─ 否 → ❌ 不靠谱（物质僵化）
         └─ 是 → 能否产生自增强负熵信息？
                ├─ 否 → ⚠️ 有缺陷（无护城河）
                └─ 是 → 熵增是否可控？
                       ├─ 否 → ⚠️ 有缺陷（熵增不可逆）
                       └─ 是 → ✅ 靠谱
```

```

  负熵信息：……
  熵增风险：……

建议：若评级为"靠谱"或"有缺陷"，可进一步使用 business-launch-advisor 获取精算与行动方案。
```

## 自检清单

- [ ] 已完整解析 Idea 的五个要素
- [ ] 四个维度逐一完成提问与判定
- [ ] 最终评级有决策树路径支持
- [ ] 输出了热力学解读与类比案例

## 禁止事项

- 不替用户做业务决策（只给评级和分析）
- 不涉及精算数据收集（那是 launch-advisor 的职责）
- 不与可行性无关的内容发散讨论
- 不因用户情绪（兴奋/焦虑）而人为调高/调低评级

## 参考案例

| 评级 | 案例 | 关键特征 |
|------|------|---------|
| ✅ 靠谱 | 奈飞、AWS | 能量流稳定，负熵信息自增强 |
| ⚠️ 有缺陷 | 传统租赁 | 物质重但可通过信息优化，需验证脱实向虚可能 |
| ❌ 不靠谱 | 雅虎人工目录、诺基亚功能机 | 信息无法扩展或失效，熵增不可逆 |
